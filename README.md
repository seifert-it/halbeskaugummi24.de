# halbeskaugummi24.de

Der vermutlich spezialisierteste Webshop Deutschlands – für exakt ein halbes Kaugummi.

## Worum geht es hier?

Mein Vater hat uns als Kindern zum Geburtstag regelmäßig ein halbes Kaugummi versprochen. Das war natürlich als Scherz gemeint. Natürlich hat es uns trotzdem jedes Mal geärgert. Viele Jahre später bekommt dieses großzügige Angebot nun endlich den angemessen übertriebenen Webauftritt.

**Wichtiger Hinweis mit einem halben Augenzwinkern:** Dieses Projekt ist Satire. Es handelt sich weder um einen echten Shop noch um einen echten Chat. Es werden keine Bestellungen angenommen, keine Zahlungen verarbeitet und keine Kaugummis – weder ganze noch halbe – verschickt.

## GitHub Pages

Die Seite besteht nur aus statischen Dateien und benötigt keinen Build-Schritt.

1. Repository auf GitHub anlegen und diese Dateien hochladen.
2. Unter **Settings → Pages** als Quelle **Deploy from a branch** wählen.
3. Den Branch `main` und den Ordner `/ (root)` auswählen.
4. Speichern, kurz warten und dann sehr professionell auf den halben Erfolg anstoßen.

## Lokal ansehen

Einfach `index.html` im Browser öffnen. Für eine Vorschau über einen kleinen lokalen Webserver geht zum Beispiel auch:

```bash
python3 -m http.server 8000
```

Danach `http://localhost:8000` aufrufen.

## Inhalt

- `index.html` – die komplette Shop-Seite
- `styles.css` – Gestaltung und mobile Ansicht
- `script.js` – der halbe Warenkorb-Gag
- `assets/halbes-kaugummi.png` – das Produktbild

## Rechtliches, ungefähr

Alle Texte und Angebote sind frei erfunden und ausschließlich humoristisch gemeint. Ähnlichkeiten mit echten Kaugummis sind klebrig, aber zufällig.

Viel Spaß – und nicht alles auf einmal kauen.
